# Astra Qualification Workbench quality status

Completion and qualification differ. Existing server-authoritative Astra certification status now requires both 20 signed exact-case runs and the Native Intelligence score floor of 0.75. The Workbench uses the returned normalized candidate-model average and floor to show a non-certifiable state when all cases are complete but quality is insufficient.

The display does not infer a score, create evidence, bypass approvals or rerun paid cases. It only reflects the exact owner-scoped server verifier and preserves the existing single/batch workflow.
